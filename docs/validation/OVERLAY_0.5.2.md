# 0.5.2 최고 진행도·커스텀 텍스트·기본값

- 최고 진행도는 레벨 해시별 0~1 값으로 settings.json에 저장한다. 첫 타일 시작, 자동플레이 OFF, 맵 전체 무적/무한 판정 OFF 시도만 집계한다. 도중 해당 모드를 켜면 그 시도의 후보 기록을 폐기한다.
- 사망·클리어·재시작·맵 이탈·모드 비활성화·게임 종료 시 후보 기록을 확정한다. 클리어는 100%이며 기존 최고를 낮추지 않는다. 외형 초기화 시 최고 기록을 보존한다.
- 5번 그룹에서 최고 진행도를 개별 표시한다. 어템의 자식 텍스트라 위치·확대가 함께 적용된다. 반 줄 간격으로 아래 표시하며 새 행이 화면 아래로 잘리지 않도록 블록의 하단 여백을 확보한다.
- 6번 커스텀 텍스트 카테고리에서 최대 50개 추가·선택·삭제, 항목별 표시·멀티라인 내용·RGBA 색상·8~160 글자 크기·1920×1080 기준 좌표를 편집한다. 색상은 HEX와 기존 팔레트를 사용한다. 내용을 TMP 명령으로 해석하지 않는다. 기존 uGUI/TMP만 사용한다.
- 사용자 ZIP에서 settings/layout/keyviewer의 외형·키 지정·동작 옵션을 기본값으로 옮겼다. 개인 경로, Full 누적, 키 횟수, 이전 게임 입력 백업, 개인 프리셋 카탈로그, DLL은 가져오지 않았다. 기존 설정 파일은 덮어쓰지 않는다.
- 기본 손/발 16키, Num 별명, 오버레이 위치·크기, FPS OFF, 채터링 ON/70ms를 반영했다. 4/8/10/12/16키 지원은 유지한다.

검사 결과:

- 최고 기록·어템/레벨 해시 87개, 설정 UI 62개, 새 설정/저장/기본값 비교 281개 통과.
- 키뷰어 108개와 프리셋 93개 통과.
- 설치기 60개 및 실제 EXE의 모형 게임 폴더 설치·업데이트·이전·오류 처리 통과.
- 라이선스 원문·배포 고지 검사와 문서 링크 검사 통과.
- 실제 게임에 설치하거나 인게임 육안 검증은 하지 않았다. UI 검사는 실제 설정창 코드를 사용하는 모형과 빌드 검사를 통해 수행했다.
