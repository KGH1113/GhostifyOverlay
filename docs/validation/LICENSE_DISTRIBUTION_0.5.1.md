# 0.5.1 배포 라이선스 정리

- 기능과 버전은 유지하고 구성 요소별 적용 범위를 LICENSE.md에 명시했다. 자체 코드에 신규 라이선스를 임의로 부여하지 않았다.
- JipperResourcePack의 Copyright (c) 2024, Jongyeol과 BSD-3-Clause 조건·면책 전문은 원문 그대로 보존한다. 현재 유래 파일 21 개의 소스 머리말과 derivedFiles 목록을 대응시켰다. 원본 커밋과 파일 지문도 유지한다.
- 소스·바이너리 재배포 시 고지 보존과 이름을 통한 보증·홍보 금지를 명시했다.
- Gmarket Sans 공급자 라이선스와 Noto Sans KR OFL은 보존한다. 글꼴·이미지를 코드와 같은 라이선스로 재허락하지 않는다.
- 설치기 캐릭터 및 변환 아이콘은 2026-11-02 프로젝트 소유자의 직접 제작 또는 포함 배포 허락 확인을 기록했다. 원저작자·개별 허락 문서는 별도로 수집하지 않았다.
- 사용하지 않는 Google Sans 파일과 고지를 제거하고, 옛 미리보기 생성기는 현재 사용하는 Gmarket Sans를 참조하도록 바꿨다.
- ZIP과 EXE의 실제 Payload.zip에 라이선스 정책·고지·출처 기록이 소스와 같은 SHA256으로 포함되는지 자동 검사한다. EXE manifest의 해당 해시도 확인한다. 게임·라이브러리 DLL을 추가 동봉하면 검사가 실패한다.

검증 결과:

- Release 빌드와 EXE/ZIP 생성 성공. 배포 파일 15개.
- 원본 BSD·글꼴 라이선스 전문 지문 및 소스 표시 검사 통과.
- 고지 누락·변조·중복 및 별도 의존 DLL 동봉을 거부하는 4개 음성 검사와 정상 패키지 검사 통과.
- 실제 EXE/ZIP에서 7개 정책·고지·출처 파일 비교 통과.
- 설치기 60개 검사 및 EXE의 별도 모형 게임 폴더 설치·업데이트·이전·잘못된 경로 처리 통과.
- 키뷰어 108개 회귀 검사, 저장소 구조·문서 링크 55개 검사 통과.

이 기록은 확인한 구성 요소와 자동 검사 결과를 설명한다. 모든 제3자 권리나 배포 상황에 대한 법적 보증은 아니다. 실제 게임 폴더·사용자 설정은 수정하지 않았으며 비공개 0.6.1 코드는 포함하지 않았다.
