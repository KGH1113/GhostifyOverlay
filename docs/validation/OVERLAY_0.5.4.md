# 0.5.4 현재 맵 기록 개별 초기화

- 오버레이 5 · 시도 횟수에 현재 맵 시도 횟수 초기화 / 현재 맵 최고 진행도 초기화 버튼을 추가했다.
- 확인창을 열 때 최신 레벨 해시를 확보하고, 적용 직전에 다시 해시를 계산해 비교한다. 맵이 없거나 확인 중 맵이 바뀌면 변경하지 않는다. 에디터에서 불러온 맵도 지원한다.
- 시도 횟수 초기화는 현재 맵의 세션 Attempt/Prac과 영구 Full/Full Prac만 삭제한다. 확인 가능한 현재 경로/공식 맵의 이전 키도 함께 제거하여 이전 기록 재이전을 막는다. 최고 진행도와 다른 맵 기록은 보존한다.
- 최고 진행도 초기화는 현재 해시의 Best만 삭제하고, 현재 시도의 임시 후보도 폐기한다. 다음 시도부터 새 최고를 기록한다. 시도 횟수와 다른 맵 기록은 보존한다.
- 영구 기록은 복사본에서 수정하여 settings.json에 먼저 저장한다. 저장 실패 시 원본 사전 참조를 복원하고 세션/임시 후보는 변경하지 않는다.
- 실제 사용자 기록을 초기화하지 않았으며 모형 데이터로 검증했다.

검증:

- 어템/최고 기록 101개: 대상 맵의 4개 카운터, 반대 기록과 타 맵 보존, 저장 실패 복원, 이전 경로 재이전 방지, 임시 Best 재등장 방지, 다음 시도 집계, 대상 맵 변경 및 메뉴에서의 거부.
- UI 73개: 확인 전 무변경, 취소, 각 버튼의 독립 작업, 맵 변경 거부, 맵 없음 비활성화, 기존 편집·프리셋 동작.
- 기본값·저장 281개, 문서 링크 55개 및 배포 고지 검사 통과.
- Release/EXE/ZIP 빌드와 설치기 모형 검증을 수행했다. 실제 인게임 육안 검증은 수행하지 않았다.
