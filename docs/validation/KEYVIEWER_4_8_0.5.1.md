# 0.5.1 손 4키·8키 추가

- 기존 0.5.1에 손 4키·8키 선택과 기본 프리셋을 추가했다. 버전은 0.5.1로 유지한다.
- 참고 원본 JipperResourcePack ac6d641에는 손 4키·8키가 없어 기존의 50×50 키, 단일 상단 레인, 하단 KPS/Total 규칙으로 확장했다. 4키는 가로 폭을 네 키에 맞추고 8키는 기존 상단 여덟 키 폭을 유지한다.
- 기존 enum 값(12키=0, 16키=1, 10키=3)과 기본 10키 설정을 유지한다. 삭제된 20키 값 2는 재사용하지 않는다.
- 각 배치의 입력 키·표시 이름·고스트 키는 별도 배열로 저장한다. 기본 프리셋, 저장·재열기·내보내기·가져오기와 게임 입력 연동은 같은 배치를 사용한다.

검증:

- Release 빌드와 설치 EXE/ZIP 생성 성공.
- 키뷰어 108개 검사: 새 배치, 0/3/30 간격, 키·레인 크기, KPS/Total 폭, JSON 복원, 기존 입력·고스트 레인 회귀.
- 프리셋 93개 검사: 손 5종 × 발 5종 왕복, 새 배치의 이름·고스트 키 재열기/공유, 기존 프로필 보존.
- Feedback v2/v4/v6: 89/50/260개 검사 통과. v2의 오래된 노란색 하드코딩 검사는 리셋 직후 실제 색을 비교하도록 수정했다.
- 설치기 60개 검사 및 실제 EXE의 별도 게임 폴더 모형 설치·업데이트·이전·오류 처리 통과.

실제 게임 폴더와 사용자 설정은 변경하지 않았다. 실제 인게임 육안 확인은 수행하지 않았다. 비공개 0.6.1 코드와 기록은 포함하지 않는다.
