# 0.5.3 재시작 최고 기록·커스텀 텍스트 편집

원인:

Start_Rewind는 음악 시작을 예약하며 OnMusicScheduled에서 Countdown/PlayerControl 상태로 바뀐다. 이전 시도의 Fail/Fail2 상태가 재시작 후에도 잠시 남을 수 있다. 0.5.2는 이 시점에 새 최고 기록 추적을 시작한 후, 이전 Fail을 새 시도의 사망으로 처리해 추적을 즉시 끝낼 수 있었다.

수정:

- 첫 PlayerControl을 확인할 때까지 최고 진행도 추적을 대기한다. 이전 Fail/Fail2와 Countdown 프레임에서 새 시도를 끝내거나 이전 타일의 진행도를 가져오지 않는다.
- 실제 플레이 시작 이후의 사망·클리어·무적·자동플레이·맵 이탈 규칙은 유지한다.
- 커스텀 텍스트는 각 행의 표시 토글, 인라인 멀티라인 입력, 위치·크기 조절, 색상 팔레트, 삭제와 하단 + 버튼으로 구성한다. 기존 저장 형식을 유지한다.
- 기존 LayoutEditorController에 커스텀 텍스트 편집 모드를 추가했다. 별도 캔버스의 미리보기라 게임/오버레이/항목 표시 여부와 관계없이 보인다. 원본 오버레이의 같은 텍스트는 편집 중 중복 표시하지 않는다.
- 방향키 연속 이동, Shift 빠른 이동, Ctrl+위/아래 크기, Enter 저장, Esc 취소를 지원한다. 다른 항목 선택 키는 커스텀 편집 중 적용하지 않는다.
- 임시 객체에서 좌표와 크기를 편집하여 자동 저장이 중간값을 기록하지 않는다. 저장 실패 시 원본 값을 복원하고 편집 상태를 유지한다. 취소·장면 전환도 원본 값을 바꾸지 않는다.

검증:

- 사망 상태가 두 프레임 남고 Countdown을 거쳐 첫·두 번째 재시작을 하는 회귀 재현을 포함해 어템/최고 기록 91개 통과.
- 설정 UI 67개 통과: 한 줄 추가/삭제, 줄바꿈, 메뉴 미리보기, 방향키 초안, 취소, 저장 실패 복원, Ctrl 크기와 Enter 저장, 기존 편집 동작.
- 저장·기본값 281개, 문서 링크 55개 및 배포 고지 검사 통과.
- 실제 설정창 코드의 카드 배치 데이터를 렌더링해 확인했다. 실제 게임 내 육안 검증을 대체하지는 않는다.
- 빌드 및 설치기 모형 테스트를 실행했다. 실제 게임 설치와 사용자 설정은 변경하지 않았다.
